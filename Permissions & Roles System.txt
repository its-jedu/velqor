4 Roles
Role	Permissions
superadmin	All 12 permissions
admin	All 12 permissions (backward compat alias)
moderator	manage_tournaments, view_standings, manage_tournament_players
player	None
How It Works
- HasPermission('code') → replaced with perm('code') factory that returns a permission class checking the user's role → permissions M2M relationship
- superadmin / admin roles bypass all permission checks automatically
- moderator can only access views requiring their 3 permissions; everything else returns 403
- is_superuser (Django flag) also bypasses all checks

Superadmin Can Assign Permissions
A superadmin can use /api/v1/admin/permissions/ and /api/v1/admin/roles/ to assign any permission to any role — including giving a moderator create_tournaments if desired.
Your existing IsAdminUser and IsModeratorOrAdmin classes are preserved for backward compatibility.
